# V1 时代

## 节点形式

- 扁平文本内容：
````md
# CORE AGENT 文档编辑设计

这是一个基于 **Tiptap + Yjs** 的协同编辑器。

目前 V1 的目标是：让 AI 通过 `Tool` 修改文档，而不是直接处理底层的 Yjs 数据。

## V1 编辑原则

AI 主要处理以下几种内容：

- 普通文本修改
- **加粗文本**
- *斜体文本*
- ~~删除线文本~~
- `inline code`
- 插入资源引用，例如 [[Yjs 架构设计]]

> AI 不应该直接感知 Y.Doc、RelativePosition 或 Yjs Update。

### 基础操作

1. 找到目标语义块
2. 在目标块内部定位文本
3. 执行插入、删除或者替换
4. 将修改转换成协同编辑操作

---

下面是一段代码：

```java
public void updateDocument(String documentId) {
    System.out.println("update document");
}
```
````

## Yjs 的原子事务

- 可以理解为以下的操作流程
```txt
一次语义编辑
    ↓
确定来源 origin
    ↓
Tiptap / ProseMirror 执行修改
    ↓
binding 将修改写入 Y.Doc Transaction
    ↓
Y.Doc 已完成修改
    ↓
Transaction 产生一次协同 update
    ↓
ydoc.on('update') 拿到：
    update + origin
    ↓
REMOTE？
├─ 是 → 不再上传
└─ 否 → 生成 clientUpdateId
         ↓
       WebSocket 发给 Java
         ↓
       等待 ACK
```

- 应用更新的时候会做这个检查
```typescript
// 如果更新来自服务器，则无需发送
if (origin === REMOTE_UPDATE_ORIGIN) return
```
